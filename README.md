# Trebuchet Builder

Design a small 3D-printable trebuchet, see how far it should throw, and download the STLs and a hardware list. A Quiver Design Works project, sister to [Rocket Builder](https://github.com/the-feve/rocket-builder-web).

- `geometry/trebgen/`: design maths (`params.py`), throw physics (`physics.py`), parts in build123d (`parts.py`), hardware list, assembly steps, STL/GLB/PNG export.
- `server/`: FastAPI app and the page.
